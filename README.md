# UART_Full_Duplex_Verilog
UART implementation in Verilog HDL with an FSM-based transmitter, FSM-based receiver using 16× oversampling, baud rate generator, and full-duplex communication. Supports 115200 baud PC-to-FPGA serial communication with echo-back testing via PuTTY. Verified through simulation and FPGA implementation.
